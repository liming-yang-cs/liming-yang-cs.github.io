# Yang Liming — personal research page

A responsive, single-page personal site for GitHub Pages. Built with plain HTML, CSS, and a tiny JavaScript file; no build step or framework required.

## Publish with GitHub Pages

1. Create a repository named **`YOUR-GITHUB-USERNAME.github.io`** (replace the placeholder with your exact GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `favicon.svg` to the repository root. Keep `README.md` if you'd like.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Visit `https://YOUR-GITHUB-USERNAME.github.io` after GitHub finishes publishing.

GitHub's official guide: https://docs.github.com/en/pages/quickstart

## Personalise it

- Change the copy, project descriptions, affiliations, and email in `index.html`.
- Adjust colours, typography, spacing, and responsive behaviour in `style.css`.
- The abstract orbital artwork is inline SVG in `index.html`; it doesn't need an external image asset.
- Google Fonts are optional. If they're blocked or unavailable, the site falls back to system fonts.

## Notes

- The page intentionally doesn't invent links to GitHub, Google Scholar, ORCID, or papers. Add them once you have the exact public URLs you want to share.
- This is a static site; no server, package installation, or build command is needed.
